はじめての準備（1回だけ・約5分）

児童のPDFは、先生のGitHubにつくる非公開の保管庫に入ります。サーバーはいりません。PDFは送る前に暗号化されるので、先生のパスワードなしでは中を見られません。

1
保管庫をつくる
GitHubで保管庫をつくる ↗
名前「print-box」・「Private」が入った画面が開きます。いちばん下の Create repository を押すだけです。
2
鍵（トークン）をつくる
GitHubで鍵をつくる ↗
  1. 画面を下へスクロールすると「Repository access」（リポジトリへのアクセス）があります。3つの中から Only select repositories に〇をつける
  2. すぐ下に出る「Select repositories」を押して、print-box にチェック（出てこないときは①の保管庫ができているか確認）
  3. いちばん下の Generate token を押す
  4. 出てきた github_pat_… をコピーする（あとでは見られません）
3
鍵をはりつける

先生のパスワードを決める

PDFを開くためのパスワードです。わすれると、送られたPDFは開けません（作り直せば、また使えます）。8文字以上にしてください。
