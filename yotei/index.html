AI 未設定

話した言葉や写真を、AIが正確に予定へ整理します。無料で使えます。

  1. キーを作るを押して、Googleでログイン
  2. APIキーを作成を押して、出てきたキーをコピー
  3. ここに戻って貼り付けてつなぐ
キーを作る

キーはこの端末の中だけに保存されます。無料のキーでは、送った内容がGoogleのサービス改善に使われることがあります。

Googleカレンダー・Gmail 未設定

入れた予定がGoogleカレンダーに自動で入り、Googleの予定もここに出ます。メールから予定を探すこともできます。パソコンでの作業がおすすめです（10分ほど）。

  1. コードをコピー（あなた専用の合言葉入り）
  2. script.google.com で新しいプロジェクトを作り、中身を全部消して貼り付け、保存
  3. デプロイ → 新しいデプロイ → ウェブアプリ
  4. 実行ユーザーは自分、アクセスは全員にしてデプロイ
  5. アクセスを承認（警告が出たら「詳細」→「移動」→「許可」）
  6. 表示された …/exec のURLを下に貼ってつなぐ

前につないだ人へ：プログラムを新しくする

① コードをコピー → ② 前のプロジェクトの中身を全部消して貼り付け、保存 → ③ デプロイ → デプロイを管理 → 編集 → バージョン「新バージョン」→ デプロイ（聞かれたら許可）→ ④ ここで「つなぐ」。URLは前と同じです。

iPhoneのアラーム・タイマー 未設定

「7時にアラーム」「25分タイマー」と話すと、iPhoneの時計にそのままセットします。「ショートカット」アプリで2つ作ります。

アラーム

  1. ショートカットアプリで ＋、名前を 予定帳アラーム に
  2. アラームを作成 を追加し、時刻を ショートカットの入力 に

タイマー

  1. ＋、名前を 予定帳タイマー に
  2. タイマーを開始 を追加し、数を ショートカットの入力、単位を 分 に
ウィジェット 未設定

ホーム画面やロック画面に「つぎの予定・あと何分」を表示します。iPhoneのカレンダー（Googleカレンダーも）とリマインダーを読むので、ほかの設定はいりません。

  1. App Storeで Scriptable を入れる（無料）
  2. 下の コードをコピー
  3. Scriptableで ＋、貼り付けて名前を 予定帳 に
  4. 下の ▶ を一度押して、カレンダーとリマインダーを 許可
  5. ホーム画面を長押し → ＋ → Scriptable → 大きさを選んで追加
  6. ウィジェットを長押し → ウィジェットを編集 → Script を 予定帳 に

Googleカレンダーの予定を出すには、iPhoneの「設定」→「カレンダー」→「アカウント」にGoogleを入れておきます。予定帳をGoogleとつないでいるときは、予定帳の予定（あとでの数など）も出ます。

Apple Watch・Siri 未設定

Watchに話すと、AIが整理してGoogleカレンダーと予定帳に入れます。「Hey Siri、予定帳に入れる」でもOK。AIとGoogleをつないでから使えます。

  1. ショートカットアプリで ＋、名前を 予定帳に入れる に
  2. テキストを音声入力 を追加
  3. URLエンコード を追加
  4. URL を追加して②を貼り、最後に URLエンコードされたテキスト を入れる
  5. URLの内容を取得、結果を表示 の順に追加
  6. 詳細で Apple Watchに表示 をオン

Googleカレンダーの通知と、予定帳でセットしたiPhoneのアラームは、そのままWatchでも鳴ります。
