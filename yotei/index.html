🤖 AI（聞き取り・写真の読み取り） 未設定

AIをつなぐと、話した言葉をちゃんと聞き取って、日時・場所・持ち物・アラームまで正確に整理します。写真（チラシ・プリント）の読み取りにも必要です。無料で使えます。

  1. 下の 「① キーを作るページを開く」 を押す（Googleアカウントでログイン）
  2. 青い 「APIキーを作成」（Create API key）を押す。聞かれたらそのまま「作成」
  3. 出てきた AIza… で始まる文字の横の コピー を押す
  4. この画面にもどって 「② 貼り付けてつなぐ」 を押す
① キーを作るページを開く

キーはこの端末の中だけに保存されます。無料のキーでは、送った内容がGoogleのサービス改善に使われることがあります。気になる人は有料プランのキーを使ってください。

📅 Googleカレンダー・📧 Gmail 未設定

つなぐと、入れた予定が自動でGoogleカレンダーに登録され（通知つき）、Googleカレンダーの予定もここに出ます。📧 でGmailから予定やしめ切りをさがせます。
あなたのGoogleアカウントの中に、小さなプログラム（Apps Script）を置いてつなぎます。パソコンでやるのがおすすめ（10分くらい）。

  1. 「① コードをコピー」 を押す（あなた専用の合言葉が入っています）
  2. script.google.com を開いて 「新しいプロジェクト」
  3. 最初から書いてある文字をぜんぶ消して貼り付け → 💾 保存
  4. 右上 「デプロイ」→「新しいデプロイ」 → 歯車 ⚙ →「ウェブアプリ」
  5. 「次のユーザーとして実行」= 自分、「アクセスできるユーザー」= 全員 →「デプロイ」
  6. 「アクセスを承認」→ 自分のアカウント →（警告が出たら）「詳細」→「〜に移動」→「許可」
  7. 出てきた ウェブアプリのURL（…/exec で終わる）をコピーして、下に貼る →「つなぐ」

⏰ iPhoneのアラーム・タイマー 未設定

「7時にアラームかけて」「25分タイマー」と話すと、iPhoneの時計アプリに本当にセットします。iPhoneの「ショートカット」アプリで、2つだけ作っておきます。

⏰ アラーム用

  1. 「ショートカット」アプリ → 右上の ＋
  2. 上の名前を 予定帳アラーム にする（ぴったり同じ名前）
  3. 「アクションを検索」で アラームを作成 を追加
  4. 時刻のところをタップ →「ショートカットの入力」をえらぶ → 完了

⏱ タイマー用

  1. もう一度 ＋ → 名前を 予定帳タイマー にする
  2. タイマーを開始 を追加 → 数字のところを「ショートカットの入力」、単位は 分 → 完了

セットしたあとは、左上の「◀ 予定帳」でもどってこられます。
